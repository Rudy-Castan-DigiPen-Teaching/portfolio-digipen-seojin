Project Hello Quad

3D Graphics

Project Overview

HelloQuad is a project to learn the basics of the OpenGL rendering pipeline. The goal was to display a single quad on the screen and understand how vertex buffers, shaders, and the rendering loop work together.

Tasks Completed

  • Defined OpenGL vertex data: created the quad vertex array with positions and any needed attributes.
  • Set up buffer and array objects: generated VBO, VAO, and EBO, and bound vertex attributes to the shader.
  • Wrote GLSL shaders: implemented 01_hello_quad.vert and 01_hello_quad.frag to handle vertex transformation and fragment color output.
  • Built the rendering loop: initialized the rendering context in the C++ application and rendered the quad each frame.
  • Integrated with CMake/project structure: configured the project to build and run correctly within the existing CMake setup.

Reflection

Challenge

Initially nothing appeared on screen because shader attribute locations and vertex format did not match exactly.

Solution

Debugged by verifying input layout and layout(location = ...) in GLSL, and checked buffer binding order and shader compile status.

Learned

Gained a clear understanding of the basic graphics pipeline (vertex data → shader → fragment output) and the importance of OpenGL resource management, as well as improved familiarity with project setup and CMake build flow.
