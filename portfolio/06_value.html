Project Value Noise

3D Graphics

Project Overview

This project focused on implementing a robust procedural texture generation system using the Value Noise algorithm within a custom C++ and OpenGL graphics framework. The primary goal was to construct a flexible noise generator capable of 1D, 2D, and 3D space evaluation using permutation hashing, and to visualize the seamlessly tiled results in real-time through custom shaders.

Tasks Completed

  • Project Integration: Seamlessly merged the Value Noise starter code into the existing OpenGL framework, updating the CMakeLists.txt and registering the new interactive demo in the DemosFactory module.
  • Value Noise Algorithm: Developed the core noise generator incorporating random permutation hash tables, coordinate splitting (separating fractional interpolants from base grids), and various fractional fading methods (Linear, Cosine, Smoothstep, Quintic) for smoothing out the noise boundaries.
  • Dimensional Interpolation: Programmed precise interpolators utilizing 1D Linear, 2D Bilinear, and 3D Trilinear mixing methods to evaluate glm::vec4 textures accurately across varying spatial dimensions.
  • Texture Uploading: Implemented an UploadAsRGBA method inside the Texture class using GL::TexSubImage2D to efficiently stream procedurally generated pixel data straight into the GPU's memory.
  • Shader Pipeline: Created custom simple.vert and simple.frag shaders to handle clip-space transformations and map the noise output onto an interactive full-screen quad while respecting dynamic scaling and tiling parameters.

Reflection

One notable challenge was adapting the generic noise templating mechanics alongside the concrete runtime demands of the demo. To streamline performance and reduce codebase complexity, the generic ValueNoise interface was successfully refactored into a concrete class optimized directly for the glm::vec4 color datatype. Additionally, ensuring seamless, continuous bounds across multi-dimensional grids required precise logic when slicing float coordinates into their base integer and fractional offsets. Overall, this project significantly deepened my understanding of procedural noise behavior, the importance of permutation hashing for maintaining pseudo-random consistency, and the intricacies of bilinear and trilinear interpolation for fluid graphical visualizations.
