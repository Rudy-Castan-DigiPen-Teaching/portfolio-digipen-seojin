Project Procedural Geometric Modeling

3D Graphics

Project Overview

This procedural geometric modeling demo shows a browser-ready port of a desktop OpenGL/SDL application, built with Emscripten and configured for a portfolio-friendly web entry point.

Tasks Completed

  • Reviewed and adjusted the web build configuration for Emscripten, including CMake presets and target settings.
  • Fixed Emscripten-specific compilation issues in Mesh.cpp and D02ProceduralMeshes.cpp.
  • Ensured web debug, web developer-release, and web release targets can configure and build successfully.
  • Set up a web shell template using index_shell.html for browser runtime behavior.
  • Added a portfolio-friendly HTML redirect page so the procedural mesh demo can be opened directly with graphics_fun.html?start=meshes.

Technologies Used

  • C++
  • CMake
  • Emscripten
  • WebGL / SDL2
  • GLM, GSL, Dear ImGui
  • Reflection

Reflection

The main challenge was porting a desktop OpenGL/SDL application into a browser environment with Emscripten. Toolchain and path issues, along with strict compiler warnings under -Werror, required precise source fixes.

I cleaned up web-specific CMake/Emscripten options, resolved compiler warnings, and made the code compatible with browser build settings. The result is a direct portfolio entry point for the procedural mesh demo rather than only a generic build artifact.

I learned that Emscripten builds require careful handling of build options and runtime HTML integration, and that browser builds can expose code issues desktop builds may hide.
